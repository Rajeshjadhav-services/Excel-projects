# Excel E-commerce Sales Dashboard

## Project Overview
Created an interactive Excel dashboard to analyze e-commerce sales data and understand sales performance.

## Tools Used
- Microsoft Excel

## Skills Demonstrated
- Data Cleaning
- Pivot Tables
- KPI Cards
- Charts and Data Visualization
- Sorting and Filtering

## Key Insights
- Analyzed total sales and product performance.
- Identified top 10 products by sales.
- Presented key metrics using KPI cards and charts.
